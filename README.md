# Ядро для интернет-магазина
## Описание
Цель данного проекта разработка ядра для интернет-магазина используя такой метод разработки как ООП

## Установка
1. **Клонируйте репозиторий**
        [клик](https://github.com/HI-TECHSHOTGUN/OOP.git)
## Зависимости и виртуальное окружение:
1. **Виртуальное окружение** (в данном случае Poetry) установки не требует и идёт в комплекте при клонировании репозитория.
2. **Зависимости** также можно посмотреть в этом файле [клик](pyproject.toml)

## Функционал проекта:
1. Распределение по названиям и характеристикам
2. Отслеживание цены и стоимости
3. Отслеживание общего количества категорий товаров
4. Отслеживание количества самих товаров

### Запуск проекта:
Для запуска проекта выполните
    ```
    python main.py
    ```
### Тестирование:
Для тестирования программы запустите в терминале следующую команду:
    ```
    pytest
    ```
Для просмотра покрытия тестов запустите в терминале следующую команду:
    ```
    poetry run pytest --cov
    ```
